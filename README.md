# Oculus Dei

A spy satellite simulator in your browser, except the data is real. Live open source spatial intelligence on a photorealistic 3D globe.

This branch contains the Oculus Dei application, forked from [bilawalsidhu/gods-eye-view](https://github.com/bilawalsidhu/gods-eye-view).

## About

Oculus Dei is an interactive 3D globe application that brings real-time spatial intelligence to your browser. It visualizes aircraft, vessels, satellites, and other real-world data on a photorealistic globe.

## Getting Started

See the [main repository](https://github.com/yoda-3x3/oculus-dei) for installation and development instructions.
